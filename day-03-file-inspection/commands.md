# Day 3: Reading & Inspecting Files

1. cat: It shows to display to what is in a file.
2. less: It opens files but in if it a large one, it allows to scroll.
3. head: It shows what a file start with. The first 10 lines.
4. head -n: It shows a specific number of lines from the beginning of the file.
5. tail: It shows what a file end with. The last 10 lines.
6. tail -f: It monitors the file, watches for new lines.
7. wc: It counts lines, words and bytes of files. 
8. wc -l: It counts only the lines of files.
9. file: It identifies the file type.
10. stat: It gives you detailed information about files.
