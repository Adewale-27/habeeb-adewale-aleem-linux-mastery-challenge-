# What surprised me
'ln' after the original filename is deleted the hard link still works perfectly, while the 'ln -s' throws an error. 
'pushd' this command saves the path you're currently working on and open a new path. Example: currently on the documents path and run 'pushd /etc' it save the document path, display it and move to the /etc path.
'popd' this command returns you back the path before running pushd
