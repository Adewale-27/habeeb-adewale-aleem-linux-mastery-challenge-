1. `dnf update` — Updates installed packages to newer available versions and refreshes repository metadata as needed.

2. `dnf install` — Installs a package and its required dependencies.

3. `dnf remove` — Removes an installed package.

4. `dnf search` — Searches enabled repositories for packages matching a search term.

5. `yum install` — Installs packages using the YUM command; on modern Fedora/RHEL-based systems, YUM is generally provided by or integrated with DNF.

6. `rpm -qa` — Lists all installed RPM packages.

7. `snap install` — Installs software distributed as a Snap package.

8. `add-apt-repository` — Adds an APT repository on Debian/Ubuntu systems.

9. `dpkg -i` — Installs a local `.deb` package.

10. `pip / npm install` — Installs Python packages with pip or Node.js packages with npm.
