## Today's tasks

- Understand the DNF package manager
- Understand the relationship between DNF and YUM
- Search for and install packages with DNF
- Verify installed RPM packages
- Understand alternative package installation methods
- Compare DNF workflows with the APT workflow from Day 13

## What surprised me

I discovered that DNF is not the native package manager on Ubuntu. Ubuntu uses APT, while DNF is commonly used on Fedora, RHEL-based systems, and related distributions.

I also learned that `rpm -qa` can be used to list installed RPM packages.
