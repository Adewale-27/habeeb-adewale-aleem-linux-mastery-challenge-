## Day 26 Drill

# task: Identify your machine's IP address

command: ip a

# task: Identify the default gateway

command: ip route

# task: Test connectivity to a public host

command: ping -c 4 8.8.8.8

# task: Fetch content from a URL

command: curl https://example.com

# task: Fetch HTTP headers only

command: curl -I https://example.com

# task: Download content from a URL

command: wget https://example.com

# task: List every listening TCP and UDP port

command: netstat -tulnp

# task: List every listening network socket

command: ss -tulnp

# task: Display the system hostname

command: hostname

# task: Display detailed hostname information

command: hostnamectl
