# Day 18: Vim Fundamentals

## Today's commands

Today's checkpoint focuses on Vim fundamentals, Vim modes, file editing, saving, quitting, and basic text manipulation.

The 10 commands covered today are documented in  `commands.md`.

## Today's tasks

- Open a file in Vim
- Enter insert mode with `i`
- Return to normal mode with `Esc`
- Save changes with `:w`
- Quit Vim with `:q`
- Save and quit with `:wq` or `:x`
- Quit without saving with `:q!`
- Delete a line with `dd`
- Copy and paste a line with `yy` and `p`
- Undo and redo changes with `u` and `Ctrl+r`

## The drill

I opened a new file in Vim, entered insert mode, and typed three lines of text.

I then saved the file and reopened it. I deleted the middle line using `dd`, then used `u` to undo the deletion and confirmed that the line was restored.

Finally, I saved the file and quit Vim using `:wq`.

## What I learned

The checkpoint showed how Vim uses different modes for editing and running commands.

I learned how `i` enters insert mode and how `Esc` returns to normal mode.

I also learned how `:w`, `:q`, `:wq`, `:x`, and `:q!` are used to save, quit, save and quit, or quit without saving changes.

Most importantly, I practiced basic Vim editing commands such as `dd`, `yy`, `p`, `u`, and `Ctrl+r` for deleting, copying, pasting, undoing, and redoing changes.
