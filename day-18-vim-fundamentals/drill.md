## Day 18 Drill

# task: Open a new file in Vim

command: vim file.txt

# task: Enter Insert mode

command: i

# task: Type three lines of text

text:
Debian Family is among the Linux Distribution Families
Ubuntu serves as an upstream for LinuxMint and others in the family
It uses DPKG-based APT package manager

# task: Return to Normal mode

command: Esc

# task: Save the file

command: :w

# task: Quit Vim

command: :q

# task: Reopen the file

command: vim file.txt

# task: Delete the middle line

command: dd

# task: Undo the deletion

command: u

# task: Save and quit Vim

command: :wq
