# Day 1: Where Am I? Basic Orientation

1. pwd : It shows the path of the current directory.
2. ls : It lists file and directories, leaving out the ones that starts with '.'.
3. ls -l : '-l' lists files and directories in long format. It shows the permissions, links, owner, group, size, date/time and name of the files and directories.
4. ls -a : It shows all files and directories, including the ones hidden ones(the ones that starts with '.').
5. ls -la : It lists every detail of all the files and directories.
6. ls -lh : It lists files and directories with detailed information in human-readable file size. Instead of showing 4096, it shows 4.0k making the file an easy readable one.
7. cd : (change directory) It's used to move into directory. 'cd documents' it moves into the documents directory.
8. cd .. : (change directory up one level) It moves the directories to their parent directories. '/home/user/Documents', it moves into the parent directory "user".
9. cd ~ :  It moves back to the home directory.
10. cd - : It moves back to the previous directory and display the directory.
