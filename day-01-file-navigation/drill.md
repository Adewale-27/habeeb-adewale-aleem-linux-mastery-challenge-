# Day 01 Drill

## show the current path
command: pwd

## list all files including the hidden with details
command: ls -la

## list the file size in human-readable format
command: ls -lh

## move into the download directory
command: cd downloads

## move back to the home directory
command: cd ~

## move back to the previous directory and print (display) the result on your screen
command: cd -
