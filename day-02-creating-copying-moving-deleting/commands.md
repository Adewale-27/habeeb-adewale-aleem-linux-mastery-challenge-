# Day 2: Creating, Copying, Moving, Deleting

1. mkdir : (make directory) It creates a new directory/folder
2. mkdir -p : It creates parent and children directories even if the parent don't exist
3. touch : It creates an empty file, It also update the timestamp of an existing file
4. cp : It copies files
5. cp -r : It recursively copies directories and everything inside them 
6. mv : It renames and moves files and directories
7. rm : It removes files
8. rm -r : it recursively removes an empty files and directories even if the directories aren't empty
9. rm -rf : It forcefully removes directories and everything inside
10. rmdir : It removes empty directories.
