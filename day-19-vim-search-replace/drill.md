
## Day 19 Drill

# task: Open the 50-line configuration file in Vim

command: vim config.txt

# task: Jump directly to line 10

command: :10

# task: Search forward for a keyword

command: /shows

# task: Jump to the next match

command: n

# task: Jump to the previous match

command: N

# task: Replace every occurrence of one word with another

command: :%s/displays/shows/g

# task: Save and quit Vim

command: ZZ
