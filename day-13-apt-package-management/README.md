# What surprised me
'apt purge' - this command uninstalls or removes a package and its configured files.
'apt autoremove' - instead of searching for unused dependencies, with this command no longer required installed packages will be removed. 
'dpkg -l'/'dpkg -L' - these commands lists Debian packages. '-l' lists packages known to dpkg, along with their status.. '-L' shows the files the Debian package installed.
