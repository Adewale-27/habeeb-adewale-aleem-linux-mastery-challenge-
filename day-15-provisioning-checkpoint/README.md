# Day 15: Users & Packages Checkpoint

## Today's commands

Today's checkpoint combines user management, group membership, package installation, package verification, and system maintenance.

The 10 commands covered today are documented in `commands.md`.

## Today's tasks

- Create a complete team member account
- Create and assign the required group
- Set a password for the new user
- Verify the user's identity and account information
- Install the tools required for the user's role
- Verify installed packages
- Check for available package upgrades
- Review command history
- Compare the provisioning workflow with previous user and package-management exercises

## The drill

I provisioned a new team member account with a home directory, group membership, and password.

I then installed three tools required for the role and verified that the packages were installed correctly.

The complete sequence was documented so that the same process could be repeated for another team member.

## What I learned

The checkpoint showed how user management and package management can work together during system provisioning.

Creating a user is only one part of onboarding a team member. A complete provisioning process also requires the correct groups, authentication, software, and verification.
